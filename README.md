# 🛒 Zepto Clone

A modern **Zepto-inspired grocery delivery website** built with **HTML5 and CSS3**.
This project recreates the overall shopping experience with a responsive navigation bar, product categories, product cards, offers, search sections, and a detailed footer.

* 🛒 Shopping cart
